# T4.7 打包与 Compose Profiles 报告

## 范围

- `lean`：core + ClickHouse/PostgreSQL/Redis/Web + capture。
- `full-private`：lean + Elkeid HUB/Console/MongoDB/Kafka 私有 overlay。
- 新增 sensor 镜像：`lyprobe`、`capturedoctor`、`rulecompiler`。

## 一键操作

```bash
cd deploy/compose
cp lean.env.example lean.env
./lyflowctl bootstrap
./lyflowctl config
./lyflowctl up
```

Capture 镜像构建：

```bash
LYFLOW_ARTIFACTS=/opt/lyflow/artifacts \
  bash deploy/compose/build-sensor-images.sh
```

私有模式：

```bash
LYFLOW_PROFILE=full-private ./lyflowctl up
```

升级/回滚：

```bash
./lyflowctl upgrade
./lyflowctl rollback
./lyflowctl backup
```

## 回滚

- 停止 capture profile：`docker compose -f lean.yml --profile capture down`
- 删除 sensor 镜像和 `deploy/build-context`。
- core 回滚使用 `lyflowctl rollback` 恢复最近 env 备份。
- 不自动删除任何 named volume；数据卷删除必须人工确认。
