## 2. 已修复问题

### H-1 安装脚本 Host 注入（High，已修复）

`agentInstallScriptHandler` 把请求 Host 直接插入 shell 脚本。原实现还信任
`X-Forwarded-Host`，攻击者可构造带引号/分号的 Host，在管理员下载并执行安装脚本时
注入命令。

修复：

- 新增 `sanitizeRequestHost`，只接受合法 DNS/IPv4/IPv6 + 数字端口。
- 拒绝空白、引号、反引号、`;`、`$()`、`|`、`&`、`\` 等 shell 元字符。
- 安装脚本不再信任 `X-Forwarded-Host`；只使用经过校验的 `r.Host`。
- `X-Forwarded-Port` / URL port 仅接受 1–65535 数字，非法值回退默认端口。
- 新增测试 `TestInferAPIServerRejectsHostInjection`、`TestInferAPIServerIgnoresForwardedHost`、
  `TestInferAPIServerValidHosts`。

### M-1 缺少通用安全响应头（Medium，已修复）

新增 `SecurityHeaders` 中间件并包裹全部 ly-server handler：

```text
X-Content-Type-Options: nosniff
X-Frame-Options: DENY
Referrer-Policy: no-referrer
Permissions-Policy: camera=(), microphone=(), geolocation=()
```

HSTS 仍由前置 nginx/HTTPS 终止层负责。测试 `TestSecurityHeaders` 已覆盖。

### M-2 前端高危依赖（Medium/High，已修复）

审计发现 vue/server-renderer、axios、postcss、nanoid、source-map-js 存在高危
advisory。已升级并重装：

- `vue` 3.5.34 → **3.5.42**
- `axios` 1.16.0 → **1.20.0**
- 传递依赖：`postcss` 8.5.31、`source-map-js` 1.2.2、`nanoid` 3.3.20

结果：**high=0, critical=0**，剩余 1 个 moderate 为 ECharts 5.6.0 的 XSS
advisory。ECharts 修复版本为 6.1.0，属于 breaking major；本次保留 5.6.0，
要求前端对图表文本/工具提示做转义，并在后续版本单独升级验证。

### M-3 Redis 许可边界（Medium，已修复）

公开 lean profile 原来使用 `redis:7-alpine`，可能解析到非 OSI 许可的 7.4+。
已固定：

- `deploy/compose/lean.yml` 与 `lean.env.example` 使用 **Redis 7.2-alpine（BSD-3）**。
- `check-licenses.sh` 增加回归检查，拒绝 `redis:latest` / `7-alpine` / `7.4+` / `8`。
- `full-private.yml` 的 MongoDB 使用 SSPL，明确限定为私有 overlay，不进入公开产物。

## 3. 已验证的安全控制

- **SSRF**：`server/rulelifecycle/fetcher.go` 强制允许域名、http/https、禁止代理、
  固定 DNS 解析、拒绝 loopback/private/link-local/unspecified/multicast/metadata 地址，
  限制重定向、超时和响应大小；现有 `fetcher_test.go` 覆盖重定向/私网/元数据。
- **认证**：ingest v2 使用 Bearer agent credential + `X-Lyflow-Agent-ID`，固定窗口限流，
  失败审计，请求体 4 MiB / 1000 条上限。
- **WebSocket**：Origin 为空或必须与 Host 相同，按 Agent 限制并发连接。
- **路径**：RASP 资产下载使用固定 allowlist；XDR 规则文件名经过
  `safeRuleFilename`（拒绝绝对路径/`..`/非 yaml）。
- **响应**：L3 永远人工审批，L2 默认审批，四眼原则；执行器未在公开代码中实现。
- **SQL**：ClickHouse 查询使用 `quoteClickHouseString` / `quoteClickHouseTime`；
  查询层有 30 天范围、limit 和 cursor 约束。
- **秘密**：仓库无真实密码/私钥；Compose `.env` 被忽略；示例仅占位符。

## 5. 许可结论

- ly_probe：GPL-3.0，独立进程/容器，未链接进 LyFlow 二进制；对应源码、补丁和构建
  脚本见 `docs/legal/GPL-SOURCE-OFFER.md`。
- Suricata：GPL-2.0，独立容器；保留上游 source offer。
- ET Open：BSD-3-Clause，保留上游 notices。
- Elkeid HUB/Console、Elkeid RASP/HIDS 规则：私有，不进入公开产物。
- Go 直接依赖：pgx/viper/go-redis/gRPC/protobuf/websocket/YAML/gopacket 等均为
  MIT/Apache-2.0/BSD；前端生产依赖通过 `license-checker` 检查，无 GPL/AGPL/SSPL。
- 公开 lean 的 Redis 固定 7.2 BSD；MongoDB SSPL 仅限 full-private。
